# RavaLink changelog

This page tracks RavaLink releases and project-specific changes. It is separate from the upstream Lavalink changelog.

## Unreleased

- Prepare the native Rust workspace for the planned 1.0.0 release line.
- Refresh the public README and documentation branding.
- Improve release smoke-test isolation and compatibility checks.

## Planned first release

The first planned release candidate is **v1.0.0-rc.1**. It will be published only after the automated pre-RC acceptance checklist passes.

No release assets are available yet. Follow the [GitHub releases page](https://github.com/Ravalink-Project/Ravalink/releases) and join the [RavaLink Discord](https://discord.gg/PBxB5eFNUp) for release announcements.

## Upstream protocol history

RavaLink targets the Lavalink v4 API. For changes to the upstream protocol and reference implementation, see the [Lavalink documentation](https://lavalink.dev/) and [upstream changelog](https://github.com/lavalink-devs/Lavalink/blob/master/CHANGELOG.md).
